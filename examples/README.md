# Examples

This folder contains example images for testing the Pixel Image Generator.

## How to Use

1. Upload any of the following types of images to test:
   - Portrait photos
   - Landscape photos
   - Cartoon or illustration images
   - Photos with bold colors (work best for pixelation)

## Recommended Test Settings

| Effect              | Pixel Size | Grayscale | Color Reduction |
|---------------------|------------|-----------|-----------------|
| Subtle pixelation   | 4–8        | ❌         | ❌               |
| Classic pixel art   | 12–20      | ❌         | ❌               |
| Heavy mosaic        | 25–40      | ❌         | ❌               |
| Retro grayscale     | 10–15      | ✅         | ❌               |
| 8-bit palette look  | 10–16      | ❌         | ✅ (4–6 levels)  |

## Tips

- Images with high contrast and bold colors give the most dramatic pixelation effect.
- Try pixel size = 10 first (the default) to get a feel for the effect.
- Increase the pixel size to 30+ for a very abstract, mosaic-like result.
- Landscape photos (sky, fields, buildings) look great with large pixel sizes.

## Supported Formats

- **PNG** — Best quality, supports transparency
- **JPG / JPEG** — Good for photographs (smaller file size)
- **WEBP** — Modern format with good compression
